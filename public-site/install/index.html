INSTALL

Install PlayGarba.

You can use PlayGarba in any supported browser. Installing it simply gives the live player its own home-screen or desktop icon.

Open live player ↗ See instructions ↓

BY DEVICE

Start from playgarba.com.

Install the listening app, not the public website.

Your device

Choose the instructions that match your device.

Suggested steps
iPhone and iPad

Install with Safari

Use Brave to listen with background playback. To add PlayGarba to your Home Screen, use Safari:

  1. Open playgarba.com in Safari.
  2. Tap Share.
  3. Choose Add to Home Screen. On iPhone, if it is missing, scroll down, tap Edit Actions, then add Add to Home Screen.
  4. Turn on Open as Web App.
  5. Tap Add.
Apple instructions ↗
Android

Install with Brave

Install from Brave to add PlayGarba to your home screen, then use Brave for background listening.

  1. Open playgarba.com in Brave.
  2. Open the Brave menu beside the address bar.
  3. Tap Install app or Add to Home screen.
  4. Confirm, then open PlayGarba from its new home-screen icon.

BACKGROUND PLAY

Keep the Garba going in Brave.

Brave supports background playback for YouTube on Android and iPhone/iPad. Open PlayGarba in Brave, start a song, then switch apps or lock your screen. Brave can show playback controls on your lock screen.

  1. Open playgarba.com in Brave and start a song.
  2. Switch to another app or lock your phone.
  3. Use your lock-screen media controls to pause or resume.
Brave background playback ↗

On Android, you can also install PlayGarba from Brave. On iPhone and iPad, use Safari to add the PlayGarba icon to your Home Screen; keep using Brave when you want its background playback.

COMPUTER

Keep PlayGarba in a browser tab.

On Mac, Windows and Linux, playback usually continues when you switch to another tab or app. If it pauses, return to PlayGarba and press Play.

Good to know
Same player Updates Offline Remove

01 · SAME PLAYER

Installing does not create a different account or catalogue.

The installed version opens the same PlayGarba player in a standalone app-style window where your browser supports it.

02 · UPDATES

You normally do not need to reinstall it.

The web app can pick up newer player files and catalogue data through the normal browser update path.

03 · OFFLINE

Installed does not mean downloaded music.

The interface can cache selected files, but YouTube playback still needs a working internet connection.

04 · REMOVE

Remove it like another home-screen or desktop app.

You can always return to playgarba.com later and install it again.
