# Nonstop Garba on the website: inventory and YouTube route audit

**Checked:** 2026-09-28  
**Scope:** PlayGarba’s current canonical catalogue + nonstop discovery registry; YouTube browser searches only for external candidate research. No audio was downloaded or copied.  
**Counting rule:** One nonstop album, continuous master, or live event-night is one programme. Chapter rows and individual chapter timestamps are not counted as separate songs/programmes. Short ordinary song cuts are outside this audit.

## Findings at a glance

- **83 catalogue nonstop/continuous release records** matched the explicit title/entry-type criteria, excluding live-album records. This is a candidate inventory at release level; rows which represent a separate album-vs-master edition or an old catalogue record may share one underlying recording and are called out below.
- **5 additional live programme records** are full-set/live releases and are listed separately.
- The catalogue manifest currently declares **239 releases / 1706 songs**; loading all referenced chunks in this worktree yields **241 release rows / 1715 song rows**. That is a live data-quality discrepancy; treat manifest totals as stale until reconciled.
- The canonical Nonstop registry (`data/discovery/sets/index.json`) contains **83 full-set/discovery records**: **72 embeddable YouTube**, **4 YouTube external-only**, and **7 non-YouTube provider/source records**.
- Of the 83 catalogue candidates, **34 have a direct release↔discovery-set join**. Only **3** currently use the release-level `nonstopSetId` property, so the join coverage itself is weak.
- Current per-release route evidence: **27 linked YouTube master sets**, **11 single-video master with chapter/song routes**, **7 split video sets**, **3 isolated row-level YouTube route**, **3 YouTube URL only in release metadata**, **6 non-YouTube set only**, **26 with no YouTube route evidence**.
- In all, **38 releases** have evidence for one continuous YouTube video. Another **13** have incomplete/unbound YouTube evidence; **32** have no YouTube playback route in these files. A focused YouTube audit verified **10 exact older master routes** for catalogue entries: **nine lack a route in the current website source files** and *Maro Garbo* already has chaptered-master coverage. Held/new-release leads are below.

> **Do not read “YouTube source URL” as “verified playable route.”** An unbound release URL, split track uploads, or chapter IDs are not the same as a verified matching full-set master. Officiality and release identity matter; community uploads remain weaker leads.

## What “integrated” means here

- **Master set:** a catalogue release joins to a canonical discovery set whose source is an embeddable YouTube video. This is the clearest existing continuous-playback integration.
- **Chaptered master:** one YouTube video ID recurs in song source rows with timestamps. The recording is one nonstop programme; those song rows are chapter navigation only.
- **Split track routes / isolated track route:** playback evidence exists only at track level; there is no confirmed single continuous master route for the album.
- **Unbound release source:** release metadata names a YouTube URL but the canonical discovery/playback source does not bind it as the master route.
- **Non-YouTube only / no YouTube route:** available website sources do not establish a YouTube playback URL for the continuous master.
- **Discovery registry without release join:** a YouTube set may be visible in the website’s set registry but has no `linkedReleaseId`/`legacyRecordId` to the catalogue release. The registry table shows those as `—` or existing IDs.

## Data and integration cautions

- Release-to-set linkage is only 34 / 83 by direct join in the filtered continuous-release inventory; the system can have a video listed in discovery while the parent catalogue release remains unjoined.
- Duplicate/parallel representations exist. Examples in source data include Falguni 2022, Shakti-2 2022, and Rangtaali 4 (separate album and continuous-master shapes). Do not add duplicate programmes solely because the database has both album rows and master rows.
- Some chapter row counts differ from release `songCount`, and some declared release rows have no matching song rows. The report preserves declared and loaded counts rather than fabricating missing chapter titles.
- Current `data/master-intake.json` is for rights-cleared source masters and is empty; a YouTube playback route does not authorize downloading or storing audio. Keep YouTube as an external embed/link.
- Repository `AGENTS.md` requires an active, non-overlapping issue claim before editing catalogue/playback source files. This task is currently delivered as research outside the repository; source data was not changed.
