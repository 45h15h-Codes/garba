## Catalogue handling rules

- Use exact YouTube video IDs for route matching. An absent exact route is not automatically a new parent release.
- One continuous nonstop album/live set is one parent work. Its chapters or song transitions remain internal segments.
- Group multipart night/event uploads only when the same date, event, artist, and part numbering support it. Keep partials marked partial.
- Keep ordinary short standalone tracks in the single-song linkage workstream, separate from nonstop programme inventory.
- Apply the 50,000 displayed-view gate only to a popularity-qualified subset. Retain below-threshold records as research leads where useful; mark missing view counts unverified.
- Keep current displayed view counts dated and recheck before making popularity decisions.
