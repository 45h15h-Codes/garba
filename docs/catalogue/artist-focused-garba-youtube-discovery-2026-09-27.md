# Artist-Focused Garba YouTube Discovery

**Research date:** 2026-09-27  
**Scope:** YouTube pages, YouTube search results, channel pages, playlists, and video pages only.  
**Purpose:** Expand artist-focused listening options from user requests for Atul Purohit, Jignesh Kaviraj, Jaysinh Gadhavi, Aditya Gadhvi, and “Hasti,” plus closely related Garba artists. This is a targeted discovery pass, not a claim that every upload on YouTube has been indexed.

## How to use this file

- **Official/OAC** means the channel page or YouTube result visibly identified the artist, label, or Official Artist Channel. **Curated** means another channel or user assembled the playlist/video; that is useful for discovery but is not automatically an official artist release.
- A **nonstop album/live set is one video or programme** in this list. Its chapter labels describe internal sections; they are not additional standalone song entries.
- YouTube playlists can be saved from the playlist page with **Save playlist**. These are links for the user to save; this research did not save anything to an account.
- Search links are included where the YouTube result did not expose a reliable direct video ID in the rendered page. They open a YouTube search for the exact title/artist.
